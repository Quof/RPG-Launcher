EasyRPG Player Kai 2026.11.1 (EasyRPG Player 0.8.1.1), bundled with RPG Launcher

RPG Launcher uses this to run RPG Maker 2000/2003 games, chiefly ones shipped without RPG_RT.exe
(VIPRPG mode: 設定 → EasyRPGを使う; HRPG mode: ⋯ → RPG Maker 2000/2003).

EasyRPG Player Kai is SomiaWhiteRing's modified build of EasyRPG Player, the free software by the EasyRPG Project.
